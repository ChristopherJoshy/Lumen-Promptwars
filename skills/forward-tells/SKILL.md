# Forward-tells skill

Checklist for WhatsApp-viral misinformation (India-first context cues).
Source pack: `backend/app/features/analysis/agents/knowledge/forward_tells.md`.

## Checklist (run before fusing)

1. Forward shape: "forwarded many times" + urgency + vague attribution.
2. Recycled content: reverse-search image; earliest date vs claimed date;
   clipped video missing start/end; location cues vs claimed place.
3. India claim shapes: fake schemes in officialese, doctored quote cards,
   deepfaked endorsements, official-impersonation clips.
4. Search moves: core claim + "fact check" + altnews.in/boomlive.in;
   absence from mainstream outlets and fact-checkers counts against.
5. Tell the user plainly: end-to-end encryption means no platform label
   will catch this — verification is on them, and this report is the aid.
